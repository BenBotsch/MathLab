# g10: Summe der Quadrate

Referenzlösung der Holdout-Aufgabe `g10` aus `golden-m1` v1. Im Modus `BLIND_REDISCOVERY` darf kein Agent diese Datei sehen (ARCH §16.4, F-11.02).

## Beweisidee

Induktion über n. Für n = 0 sind beide Seiten 0. Gilt 6·Σ_{k≤n} k² = n(n+1)(2n+1), so folgt 6·Σ_{k≤n+1} k² = n(n+1)(2n+1) + 6(n+1)² = (n+1)(2n² + 7n + 6) = (n+1)(n+2)(2n+3).

## Hinweis für Lean

Induktion mit `Finset.sum_range_succ`, danach `ring`. Der Hinweis ist ungeprüft.
