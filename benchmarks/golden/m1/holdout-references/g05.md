# g05: n(n + 1) ist gerade

Referenzlösung der Holdout-Aufgabe `g05` aus `golden-m1` v1. Im Modus `BLIND_REDISCOVERY` darf kein Agent diese Datei sehen (ARCH §16.4, F-11.02).

## Beweisidee

Fallunterscheidung nach der Parität von n. Ist n gerade, so ist n(n + 1) als Vielfaches von n gerade. Ist n ungerade, so ist n + 1 gerade und damit auch das Produkt.

## Hinweis für Lean

`Nat.even_mul_succ_self n` Der Hinweis ist ungeprüft.
