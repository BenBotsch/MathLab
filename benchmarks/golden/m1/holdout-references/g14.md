# g14: Bernoulli-Ungleichung

Referenzlösung der Holdout-Aufgabe `g14` aus `golden-m1` v1. Im Modus `BLIND_REDISCOVERY` darf kein Agent diese Datei sehen (ARCH §16.4, F-11.02).

## Beweisidee

Induktion über n. Für n = 0 gilt 1 ≤ 1. Gilt 1 + nx ≤ (1+x)^n, so ist wegen 1 + x ≥ 0 auch (1+x)^{n+1} ≥ (1 + nx)(1 + x) = 1 + (n+1)x + nx² ≥ 1 + (n+1)x.

## Hinweis für Lean

`one_add_mul_le_pow hx n` Der Hinweis ist ungeprüft.
