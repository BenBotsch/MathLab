# g21: Summe der Fibonacci-Zahlen

Referenzlösung der Holdout-Aufgabe `g21` aus `golden-m1` v1. Im Modus `BLIND_REDISCOVERY` darf kein Agent diese Datei sehen (ARCH §16.4, F-11.02).

## Beweisidee

Induktion über n. Für n = 0 gilt 0 + 1 = F_1 = 1. Gilt Σ_{k<n} F_k + 1 = F_{n+1}, so folgt Σ_{k<n+1} F_k + 1 = F_{n+1} + F_n = F_{n+2}.

## Hinweis für Lean

Induktion mit `Finset.sum_range_succ` und `Nat.fib_add_two`. Der Hinweis ist ungeprüft.
